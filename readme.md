# Student Academic Portfolio

A full-stack web application for managing and displaying a student's academic portfolio. The application includes academic information, courses, attendance, skills, projects, and certificates.

The project demonstrates frontend development, REST API integration, CRUD operations, and MongoDB database integration.

## Project Structure

* **frontend/** - Multi-page React application built using React Router and Hooks.
* **backend/** - Node.js and Express.js REST API with Mongoose ORM for MongoDB CRUD operations.

## Key Features

* **Student Dashboard:** Overview of degree, department, semester, CGPA, and dynamic project counts.
* **Subject Attendance:** Detailed course-wise attendance tracking presented in structured tables.
* **Full CRUD Operations:** Add, view, edit, and delete projects via RESTful endpoints.
* **MongoDB Integration:** Dynamic data persistence for student projects.

## Tech Stack

* **Frontend:** React.js, React Router DOM, CSS3, Axios/Fetch API
* **Backend:** Node.js, Express.js
* **Database:** MongoDB & Mongoose ORM
